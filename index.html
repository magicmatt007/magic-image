Why Save downloads a copy

This browser isn’t allowed to write files on this computer (on company laptops this is usually set by IT), so the app can’t replace the original. Save downloads a copy instead, named like screenshot-annotated.png.

To get the copies next to your screenshots: in ’s download settings, set Location to your screenshots folder (Change…).

Paste the address into the address bar. All downloads will then go to that folder. If the Ask where to save each file setting there isn’t locked, turning it on lets you choose the folder every time. Replacing the original file directly needs IT to allow this site for file editing.
